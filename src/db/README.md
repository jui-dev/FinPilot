# src/db

Drizzle schema, migrations and the connection. The only code that touches the raw better-sqlite3 API.

- `schema.ts` — tables, CHECKs, owner-consistent composite foreign keys, indexes.
- `migrations/` — generated by `npm run db:generate` (reviewed, forward-only) plus hand-written `*_ledger_views.sql`. Never `drizzle-kit push`.
- `views.ts` — typed `.existing()` declarations of `active_transactions` and `account_entries`. All ledger reads go through these views.
- `client.ts` — `openDatabase()`: enables foreign keys explicitly on every connection (never relying on a build default).
- `npm run db:check` fails if `schema.ts` has changes no migration captures.

See [docs/tech-stack.md §3](../../docs/tech-stack.md).
